# Library & Analytics

Everything Rekordly captures lands in a **searchable library** backed by SQLite — fast, local, and yours.

## Library

- **Search** — full-text search across titles, creators, tags, and notes.
- **Tags** — label recordings however you like.
- **Collections** — group recordings into curated sets.
- **Favorites** — star the essentials.
- **Notes** — annotate a capture with context ("great ending", "clip at 42:10").

### Folder scanning

Already have a folder of recordings? Point the library scanner at it and existing media files are imported and indexed — no manual entry required.

## Storage manager

Long recordings eat disk fast. The storage manager gives you:

- **Storage breakdown** — what is using space and where.
- **Largest-file insights** — the heavy hitters at a glance.
- **Cleanup tools** — remove junk files and stale items with confidence.

## Analytics dashboard

The dashboard summarizes your recording activity:

- **Recording stats** — hours captured, sessions, and trends.
- **Storage breakdown** — per-creator and per-site usage.
- **Job outcomes** — how many recordings and downloads succeeded, failed, or were recovered after a crash.

Use it to answer the practical questions: how much am I capturing, who fills my disk, and is the pipeline healthy.
