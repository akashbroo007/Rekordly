# Built-in Video Editor

Every recording can be edited without leaving Rekordly. Open any recording in the player and the editor panel sits alongside it — trim the start and end, cut out sections, or extract the audio. Everything is **non-destructive**: every export creates a new file and a new library entry, and the original recording is never modified.

## Opening the editor

1. Open any recording from the **Library** or **Recordings** page.
2. In the player, expand the **Editor** panel.
3. Pick a tab: **Trim**, **Cut**, or **Audio**.

The timeline shows a filmstrip preview and an audio waveform so you can see exactly where speech and action start and stop. Use the in/out fields or the timeline handles to make your selection, and step frame-by-frame with the arrow keys for precise cuts.

## Trim

Keep a single span of the recording:

1. Set the **In** point where the part you want begins.
2. Set the **Out** point where it ends.
3. Preview the selection — playback auto-pauses at the out point.
4. Click **Export**.

## Cut

Remove one or more sections (up to 50) while keeping the rest — handy for stripping dead air, ads, or technical issues:

1. Mark the ranges you want to remove.
2. Preview with cuts skipped, so you hear exactly what the exported file will sound like.
3. Export. The remaining segments are joined into one file.

## Audio

Extract the audio track without re-encoding the video:

- **MP3** for universal playback, or **M4A** for smaller files at the same quality.
- The export runs on a copy of the source audio — the recording is untouched.

## Export quality

- **Fast (stream copy)** — the default. Splits and joins at keyframes with no re-encoding, so exports take seconds even for hour-long files.
- **Accurate (re-encode)** — cuts land exactly on your chosen frames instead of the nearest keyframe. Slower, but frame-precise.

## Where exports go

Every export lands in the library under **Edited**, alongside the original. From there you can tag it, favorite it, upload it to the cloud, or edit it further — edited files are just recordings.

## Tips

- **Silence detection** can suggest cut ranges for you — run it from the Cut tab and accept the spans you agree with.
- Use segment splitting during long auto-recordings first; trimming is much easier on 30-minute parts than a single 4-hour file.
- Keyboard: ←/→ step one frame, Shift + ←/→ jump one second.
