# Desktop Integration

Rekordly is a native-feeling Windows desktop app, not a browser tab pretending to be one.

## System tray

- **Live status tooltip** — hover the tray icon to see what's happening at a glance (live creators, active recordings).
- **Close-to-tray mode** — closing the window keeps the app recording in the background. Disabled by default; enable it in **Settings → General**.
- **Launch at startup / start minimized** — boot your PC and Rekordly is already watching.

## Notifications

- **In-app notification center** — a persistent log of live events, recording starts, errors, and update notices.
- **Native desktop notifications** — standard Windows toasts for live events and finished recordings, even when the main window is closed.

## Themes

- **Dark and light themes**, with OS theme sync so the app follows your system setting.
- The dark palette is tuned for OLED-friendly near-black backgrounds.

## Low-resource mode

Running Rekordly on an older machine? **Low-resource mode** trims background work (fewer parallel jobs, lighter dashboard refresh) so monitoring and recording stay dependable on weaker hardware.

## Keyboard-friendly

A command palette (`Ctrl+K`) gives you fast navigation across the dashboard, library, downloads, and settings without touching the mouse.
